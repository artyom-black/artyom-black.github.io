Everything for this app except its policy page goes in this folder.

Needed:
  info.json      name, Google Play link, description (see the main README)
  icon.webp      app icon, square (512x512 is plenty)
  poster.jpg     tall 9:16 screenshot shown on the card (keep it under ~100 KB)

Optional:
  gameplay.mp4   short tall 9:16 gameplay video, muted (~1-2 MB). No video? Delete the "video" line in info.json.
  animation.js   this app's own opening animation and page background
  animation.css  styles for that animation
  any pictures your animation uses (backgrounds, sprites...)

Without animation.js / animation.css the app uses the default animation.
You can delete this README.txt file.
