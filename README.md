# artyom-black.github.io

Website for Artyom Black's games and apps: Tintora Sort, Tunnel Ride and I Love Kanji.

- `index.html` – the whole site (styles and scripts inside)
- `img/` – icons, logos and artwork
- `media/` – gameplay videos and their poster images
- `app-ads.txt` – AdMob app-ads.txt file. Keep it in the root of the repo.

To change an app's name, description or Google Play link, edit the `APPS` list near the top of the `<script>` in `index.html`.
